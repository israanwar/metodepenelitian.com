Keputusan Default

Empat pertanyaan terbuka dari dokumen arsitektur, dijawab supaya sitemap bisa lengkap. Ini asumsi kerja, bukan keputusan final.

01

Urutan submenu di bawah nav Research.

Default: ikut urutan lifecycle — Plan → Execute (teaser publik) → Cite & Evidence. Route dasar tetap /research-hub (existing, tidak diganti nama, sesuai prinsip tidak mengubah route tanpa kebutuhan).

02

Integrations berdiri sendiri atau tersebar?

Default: tersebar di titik butuh (Zotero di Cite & Evidence, SmartPLS di halaman metode SEM, dst.) + satu halaman indeks ringkas di /integrations.

03

Research Knowledge Graph — MVP atau Phase 2?

Default: Phase 2. Berat di data model (10 tipe entitas relasional), dan 11 modul konten dasar perlu berdiri dulu supaya ada data untuk digraf-kan.

04

Analysis Advisor — decision-tree/rule engine.

Default: tetap MVP (ini kekuatan inti Analyze), tapi butuh sesi scoping teknis terpisah sebelum dikerjakan — beda kelas dari kalkulator statis yang sudah ada.

05

Temuan baru saat menurunkan sitemap: "Repository" (proposal/skripsi/tesis/disertasi/dataset/template — dari sitemap lama) tidak punya rumah eksplisit di 11 modul arsitektur baru. Docs sitemap type-nya sudah pindah konsep ke Write (dokumen) dan Execute (dataset), tapi "bank karya bisa-diunduh" sebagai satu tempat jelajah belum diputuskan masuk mana.

Default: taruh sementara sebagai bagian Discover (dijelajah seperti Papers), ditandai gap di bawah — perlu keputusan eksplisit, bukan diam-diam diputuskan sendiri.
