## Evidence method

- **VERIFIED:** an official product, help, pricing or policy page explicitly supports the capability.
- **PARTIAL:** public evidence supports only part of the lifecycle capability or with material limits.
- **NOT VERIFIED:** no adequate official public evidence was found in this audit. It does not necessarily mean the capability is absent.

Vendor claims are evidence of what a vendor publicly offers, not independent proof of accuracy, safety or output quality. Pricing, scale and capability claims can change; revalidate before a product or integration decision.

For MetodePenelitian.com, `PARTIAL` means the capability is present in locked architecture or existing product documentation but current runtime implementation has not been verified by this strategy audit. No row should be read as a shipping claim.

## Eighteen-dimension strategic analysis

| Dimension | Competitive observation | Strategic implication |
|---|---|---|
| Education | Method libraries and guided explanations reduce entry barriers. | Link learning to the live project without replacing researcher judgment. |
| Research usefulness | Point tools create immediate value within a stage. | Preserve that value downstream through canonical state. |
| Business model | Freemium/subscription, team/institution and usage-based models are publicly visible across benchmarks. | Entitlements must gate capability, not scientific truth or ownership of user data. |
| Social impact | Faster access and Indonesian localization can widen participation. | Measure access while protecting privacy, integrity and researcher agency. |
| Lifecycle coverage | Most verified strengths cluster around literature and writing. | Compete on continuity from design and data through publication impact. |
| AI capability | Search, synthesis, chat and drafting are increasingly common. | Model choice is infrastructure; governed context, evidence and evaluation are differentiation. |
| Evidence reliability | Source links, full text and citation context improve inspectability. | Record admissibility, provenance, confidence and invalidation, not only citations. |
| Methodology | Some platforms expose study snapshots or method guidance. | Build explainable fit checks connected to variables, design, sampling and data. |
| Data analysis | Named benchmarks provide little verified end-to-end statistical execution. | Preserve immutable runs and reproducibility; do not let AI invent values. |
| Academic writing | Editors, paraphrasing, drafting and templates are abundant. | Ground text in accepted research state and distinguish AI/user authorship. |
| Reference management | Export and manager integration are mature patterns. | Maintain stable reference identity and round-trip provenance. |
| Institutional compliance | Campus/journal formatting is visible in SciSpace and Indonesian platforms. | Use verified, versioned hierarchical policy packs rather than hardcoded templates. |
| Publication | Some writing platforms expose journal templates/services. | Keep Publication Gateway a readiness/router boundary with official handoff. |
| Integrations | APIs, reference-manager exports and library connections are available in parts of the market. | Integrate through capability, license, privacy and degraded-mode gates. |
| Collaboration | Team plans, shared collections and live editing are verified for several global tools. | Couple collaboration to project permissions, versions and approvals. |
| Academic integrity | Vendors describe citations, detection or originality aids, but claims vary. | Prefer traceability, transparent AI assistance and human authority over detection guarantees. |
| Indonesian localization | Local platforms explicitly target Indonesian students, campuses and language. | Go deeper into governed institution/SINTA/repository context while remaining portable. |
| International scalability | Global corpora and institution plans show cross-border demand. | Keep policies, providers, languages and destinations modular—not Indonesia-hardcoded. |

## Competitive conclusion

MetodePenelitian.com should neither race for the most generators nor claim superiority before implementation evidence exists. Its strategic space is the governed connection among lifecycle stages: **Research Digital Twin + persistent context + evidence/analysis provenance + policy-aware rendering + publication-aware handoff**.
